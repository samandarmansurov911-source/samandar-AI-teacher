# Nur Academy logotiplari

"Nur" = yorug'lik: ochiq kitobdan chiqayotgan quyosh. Ranglar video brendi bilan bir xil.

| Fayl | Qayerda ishlatish |
|---|---|
| `nur-academy-icon` | Ilova ikonkasi, kvadrat avatar |
| `nur-academy-avatar` | Instagram / Telegram profil rasmi (dumaloq) |
| `nur-academy-horizontal-dark` | Banner, YouTube/Telegram kanal sarlavhasi |
| `nur-academy-horizontal-light` | Oq fonli hujjatlar, sertifikatlar, sayt |
| `nur-academy-stacked` | Post, poster, video oxiri |
| `nur-academy-mono` | Bir rangli chop etish, muhr |

Har biri `.svg` (istalgan o'lchamda tiniq) va `.png` (2x, shaffof fon) ko'rinishida.
Matn konturga aylantirilgan, shrift o'rnatish shart emas.

**Ranglar:** to'q ko'k `#081630` → `#123A63`, oltin `#F5B700`, oq `#FFFFFF`, och kulrang-ko'k `#C8D6E8`.
**Shrift:** Inter ExtraBold (nom), Inter Medium (shior).
