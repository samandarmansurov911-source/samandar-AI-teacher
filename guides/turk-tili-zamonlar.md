# 🇹🇷 Turk tili zamonlari — to'liq qo'llanma

Bu qo'llanmada turk tilining 4 ta asosiy zamoni bor:

| № | Turkcha nomi | O'zbekcha | Qo'shimcha | Misol (gelmek – kelmoq) |
|---|---|---|---|---|
| 1 | **Şimdiki zaman** | Hozirgi davomli zamon | `-iyor` | geliyorum – kelyapman |
| 2 | **Geniş zaman** | Umumiy (doimiy) zamon | `-r / -ar / -ir` | gelirim – kelaman (odatda) |
| 3 | **Geçmiş zaman** | O'tgan zamon | `-dı` / `-mış` | geldim – keldim / gelmişim – kelibman |
| 4 | **Gelecek zaman** | Kelasi zamon | `-acak / -ecek` | geleceğim – kelaman / kelmoqchiman |

---

## 0. Avval bilish shart: unli uyg'unligi (ünlü uyumu)

Turk tilida qo'shimchalar so'zning **oxirgi unlisiga** qarab o'zgaradi.

**2 xilli uyg'unlik (a / e):**

| Oxirgi unli | Qo'shimchada |
|---|---|
| a, ı, o, u (qalin) | **a** |
| e, i, ö, ü (ingichka) | **e** |

**4 xilli uyg'unlik (ı / i / u / ü):**

| Oxirgi unli | Qo'shimchada |
|---|---|
| a, ı | **ı** |
| e, i | **i** |
| o, u | **u** |
| ö, ü | **ü** |

**Jarangsiz undoshlar:** `f, s, t, k, ç, ş, h, p` — eslab qolish uchun: **"FıSTıKÇı ŞaHaP"**.
Shu harflardan keyin `d` → `t` ga aylanadi (yap + dı → **yaptı**, iç + dı → **içti**, lekin gel + dı → **geldi**).

**Fe'l o'zagi** = infinitivdan `-mak / -mek` olib tashlanadi: gel*mek* → **gel**, yap*mak* → **yap**, oku*mak* → **oku**.

## 1. Şimdiki zaman — Hozirgi davomli zamon (`-iyor`)

**Qachon ishlatiladi:** hozir, shu daqiqada bo'layotgan ish; yaqin kelajak reja; hozirgi davrdagi holat.
O'zbekchada: *-yapman, -moqdaman*.

### Yasalishi
`o'zak + ı/i/u/ü + yor + shaxs qo'shimchasi`

- Undosh bilan tugasa: gel → gel**iyor**, yaz → yaz**ıyor**, otur → otur**uyor**, gör → gör**üyor**
- Unli bilan tugasa, unli qo'shilmaydi: oku → oku**yor**, yürü → yürü**yor**
- **a / e** bilan tugasa, u **ı/i/u/ü** ga aylanadi: bekle → bekl**iyor**, anla → anl**ıyor**, ara → ar**ıyor**, söyle → söyl**üyor**

### Tuslanishi

| Shaxs | Bo'lishli (+) | Bo'lishsiz (–) | So'roq (?) |
|---|---|---|---|
| Ben | geliyor**um** | gel**m**iyorum | geliyor **muyum**? |
| Sen | geliyor**sun** | gelmiyorsun | geliyor **musun**? |
| O | geliyor | gelmiyor | geliyor **mu**? |
| Biz | geliyor**uz** | gelmiyoruz | geliyor **muyuz**? |
| Siz | geliyor**sunuz** | gelmiyorsunuz | geliyor **musunuz**? |
| Onlar | geliyor**lar** | gelmiyorlar | geliyor**lar mı**? |

> 💡 `-yor` hech qachon o'zgarmaydi, shuning uchun shaxs qo'shimchalari doim **u** bilan: -um, -sun, -uz, -sunuz.
> Inkorda: `-me/-ma` + `-iyor` → **-miyor / -mıyor / -muyor / -müyor** (yap**mıyor**um, oku**muyor**um).

### Istisnolar
| Infinitiv | Şimdiki zaman |
|---|---|
| git**mek** (bormoq) | **gid**iyorum |
| et**mek** (qilmoq) | **ed**iyorum |
| de**mek** (demoq) | **di**yorum |
| ye**mek** (yemoq) | **yi**yorum |

### Misollar
- Şu an kitap **okuyorum**. — Hozir kitob o'qiyapman.
- Ahmet televizyon **izliyor**. — Ahmet televizor ko'ryapti.
- Yarın İstanbul'a **gidiyoruz**. — Ertaga Istanbulga ketyapmiz.
- Türkçe **öğreniyor musun**? — Turkcha o'rganyapsanmi?

**Vaqt so'zlari:** şu an, şimdi, şu sıralarda, bugünlerde, artık.

## 2. Geniş zaman — Umumiy (doimiy) zamon (`-r / -ar / -ir`)

**Qachon ishlatiladi:**
- odatlar, takrorlanadigan ishlar — *Her sabah kahve içerim.* (Har tong qahva ichaman.)
- umumiy haqiqatlar — *Su 100 derecede kaynar.* (Suv 100 darajada qaynaydi.)
- iltimos va taklif — *Kapıyı açar mısın?* (Eshikni ochib yuborasanmi?)
- va'da — *Yarın ararım.* (Ertaga qo'ng'iroq qilaman.)
- maqollar — *Damlaya damlaya göl olur.*

O'zbekchada: *-aman, -asan, -adi* (odatiy ma'noda).

### Yasalishi — 3 ta qoida

| Qoida | Qo'shimcha | Misollar |
|---|---|---|
| 1. O'zak **unli** bilan tugasa | **-r** | oku → oku**r**, bekle → bekle**r**, anla → anla**r** |
| 2. **Bir bo'g'inli**, undosh bilan tugasa | **-ar / -er** | yaz → yaz**ar**, iç → iç**er**, sev → sev**er**, yap → yap**ar** |
| 3. **Ko'p bo'g'inli**, undosh bilan tugasa | **-ır / -ir / -ur / -ür** | çalış → çalış**ır**, konuş → konuş**ur**, getir → getir**ir**, düşün → düşün**ür** |

### 13 ta istisno (bir bo'g'inli, lekin `-ır/-ir/-ur/-ür` oladi)

| | | | |
|---|---|---|---|
| al → al**ır** (olmoq) | bil → bil**ir** (bilmoq) | bul → bul**ur** (topmoq) | dur → dur**ur** (to'xtamoq) |
| gel → gel**ir** (kelmoq) | gör → gör**ür** (ko'rmoq) | kal → kal**ır** (qolmoq) | ol → ol**ur** (bo'lmoq) |
| öl → öl**ür** (o'lmoq) | san → san**ır** (o'ylamoq) | ver → ver**ir** (bermoq) | var → var**ır** (yetib bormoq) |
| vur → vur**ur** (urmoq) | | | |

Yana: git → **gider**, et → **eder** (t → d).

### Tuslanishi (yazmak – yozmoq)

| Shaxs | Bo'lishli (+) | Bo'lishsiz (–) | So'roq (?) | Bo'lishsiz so'roq |
|---|---|---|---|---|
| Ben | yazar**ım** | yaz**mam** | yazar **mıyım**? | yazmaz **mıyım**? |
| Sen | yazar**sın** | yaz**mazsın** | yazar **mısın**? | yazmaz **mısın**? |
| O | yazar | yaz**maz** | yazar **mı**? | yazmaz **mı**? |
| Biz | yazar**ız** | yaz**mayız** | yazar **mıyız**? | yazmaz **mıyız**? |
| Siz | yazar**sınız** | yaz**mazsınız** | yazar **mısınız**? | yazmaz **mısınız**? |
| Onlar | yazar**lar** | yaz**mazlar** | yazar**lar mı**? | yazmaz**lar mı**? |

> ⚠️ Inkorda **-maz/-mez**, lekin **Ben** va **Biz**da `z` tushib qoladi: yaz**mam**, yaz**mayız** (gel**mem**, gel**meyiz**).
> Inkor shaklida 3 ta qoida va istisnolar **ishlamaydi** — hamma fe'l bir xil: `-maz/-mez`.

### Misollar
- Ben sabahları erken **kalkarım**. — Men ertalablari erta turaman.
- Kedi süt **içer**. — Mushuk sut ichadi.
- O sigara **içmez**. — U sigaret chekmaydi.
- Bana yardım **eder misin**? — Menga yordam berasanmi?

**Vaqt so'zlari:** her gün, her zaman, genellikle, bazen, sık sık, asla, hiç.

## 3. Geçmiş zaman — O'tgan zamon

Turk tilida o'tgan zamonning **ikki** asosiy turi bor:

### 3A. Görülen geçmiş zaman (`-dı`) — aniq o'tgan zamon

**Qachon:** gapiruvchi ishni **o'zi ko'rgan / aniq biladi**. O'zbekchada: *-dim, -ding, -di*.

**Yasalishi:** `o'zak + dı/di/du/dü` (jarangsiz undoshdan keyin **tı/ti/tu/tü**)

- gel → gel**di**, oku → oku**du**, gör → gör**dü**, al → al**dı**
- yap → yap**tı**, git → git**ti**, iç → iç**ti**, konuş → konuş**tu**

| Shaxs | Bo'lishli (+) | Bo'lishsiz (–) | So'roq (?) |
|---|---|---|---|
| Ben | geldi**m** | gel**me**dim | geldim **mi**? |
| Sen | geldi**n** | gelmedin | geldin **mi**? |
| O | geldi | gelmedi | geldi **mi**? |
| Biz | geldi**k** | gelmedik | geldik **mi**? |
| Siz | geldi**niz** | gelmediniz | geldiniz **mi**? |
| Onlar | geldi**ler** | gelmediler | geldiler **mi**? |

> 💡 Bu zamonda so'roq yuklamasi `mi` **eng oxirida** keladi (shaxs qo'shimchasidan keyin): geldin **mi**?

**Misollar:**
- Dün sinemaya **gittim**. — Kecha kinoga bordim.
- Kahvaltı **yaptın mı**? — Nonushta qildingmi?
- Onlar ödevi **yapmadılar**. — Ular uy vazifasini qilmadilar.

### 3B. Duyulan (öğrenilen) geçmiş zaman (`-mış`) — eshitilgan o'tgan zamon

**Qachon:** ishni **o'zi ko'rmagan**, boshqadan eshitgan yoki keyin bilib qolgan; ajablanish.
O'zbekchada: *-ibdi, -gan ekan, -ibman*.

**Yasalishi:** `o'zak + mış/miş/muş/müş`

| Shaxs | Bo'lishli (+) | Bo'lishsiz (–) | So'roq (?) |
|---|---|---|---|
| Ben | gelmiş**im** | gel**me**mişim | gelmiş **miyim**? |
| Sen | gelmiş**sin** | gelmemişsin | gelmiş **misin**? |
| O | gelmiş | gelmemiş | gelmiş **mi**? |
| Biz | gelmiş**iz** | gelmemişiz | gelmiş **miyiz**? |
| Siz | gelmiş**siniz** | gelmemişsiniz | gelmiş **misiniz**? |
| Onlar | gelmiş**ler** | gelmemişler | gelmiş**ler mi**? |

**Misollar:**
- Ali dün hasta**lanmış**. — Ali kecha kasal bo'lib qolibdi (eshitdim).
- Vay, çok **büyümüşsün**! — Voy, juda katta bo'lib qolibsan!
- Bir varmış, bir yokmuş... — Bor ekan, yo'q ekan... (ertaklar boshlanishi)

### `-dı` va `-mış` farqi

| -dı | -mış |
|---|---|
| Ali **geldi**. — Ali keldi (o'zim ko'rdim). | Ali **gelmiş**. — Ali kelibdi (eshitdim / endi bildim). |

**Vaqt so'zlari:** dün, geçen hafta, geçen yıl, önce, az önce, demin, 2010'da.

## 4. Gelecek zaman — Kelasi zamon (`-acak / -ecek`)

**Qachon:** kelajakdagi ish, reja, qaror, bashorat. O'zbekchada: *-aman, -moqchiman, -ajakman*.

### Yasalishi
`o'zak + (y) + acak/ecek + shaxs qo'shimchasi`

- Undosh bilan tugasa: gel → gel**ecek**, yap → yap**acak**
- Unli bilan tugasa, **y** qo'shiladi: oku → oku**yacak**, bekle → bekle**yecek**

> ⚠️ Unli bilan boshlanadigan shaxs qo'shimchasidan oldin **k → ğ** bo'ladi: gelece**k** → gelece**ğ**im, gelece**ğ**iz.

### Tuslanishi

| Shaxs | Bo'lishli (+) | Bo'lishsiz (–) | So'roq (?) |
|---|---|---|---|
| Ben | geleceğ**im** | gel**me**yeceğim | gelecek **miyim**? |
| Sen | gelecek**sin** | gelmeyeceksin | gelecek **misin**? |
| O | gelecek | gelmeyecek | gelecek **mi**? |
| Biz | geleceğ**iz** | gelmeyeceğiz | gelecek **miyiz**? |
| Siz | gelecek**siniz** | gelmeyeceksiniz | gelecek **misiniz**? |
| Onlar | gelecek**ler** | gelmeyecekler | gelecek**ler mi**? |

### Istisnolar
| Infinitiv | Gelecek zaman |
|---|---|
| gitmek | **gid**eceğim |
| etmek | **ed**eceğim |
| demek | **di**yeceğim |
| yemek | **yi**yeceğim |

### Misollar
- Yarın sana **yazacağım**. — Ertaga senga yozaman.
- Gelecek yıl Türkiye'ye **gideceğiz**. — Kelasi yil Turkiyaga boramiz.
- Bu akşam ne **yapacaksın**? — Bu kech nima qilmoqchisan?
- O bu işi **yapmayacak**. — U bu ishni qilmaydi.

> 🗣 So'zlashuvda ko'pincha qisqa aytiladi: *geleceğim → gelicem*, *yapacağım → yapıcam*. Yozuvda esa to'liq shakl ishlatiladi.

**Vaqt so'zlari:** yarın, öbür gün, gelecek hafta, haftaya, seneye, ileride, birazdan.

|---|---|---|---|---|---|
| Ben | yapıyorum | yaparım | yaptım | yapmışım | yapacağım |
| Sen | yapıyorsun | yaparsın | yaptın | yapmışsın | yapacaksın |
| O | yapıyor | yapar | yaptı | yapmış | yapacak |
| Biz | yapıyoruz | yaparız | yaptık | yapmışız | yapacağız |
| Siz | yapıyorsunuz | yaparsınız | yaptınız | yapmışsınız | yapacaksınız |
| Onlar | yapıyorlar | yaparlar | yaptılar | yapmışlar | yapacaklar |

**Inkor (Ben):** yapmıyorum · yapmam · yapmadım · yapmamışım · yapmayacağım

## 6. Bonus: murakkab o'tgan zamonlar (`-dı` qo'shilganda)

Har bir zamonga `-dı` qo'shib, uning o'tgan shaklini olish mumkin:

| Shakl | Misol | Ma'nosi |
|---|---|---|
| -iyor**du** | geliyordum | kelayotgan edim |
| -ar**dı** | gelirdim | kelardim (ilgari odatim edi) |
| -mış**tı** | gelmiştim | kelgan edim (undan oldin) |
| -acak**tı** | gelecektim | kelmoqchi edim (lekin kelmadim) |

## 7. Tez eslab qolish uchun xulosa

| Zamon | Formula | Inkor | So'roq (sen) |
|---|---|---|---|
| Şimdiki | o'zak + **iyor** + um | gel**miyor**um | geliyor musun? |
| Geniş | o'zak + **r/ar/ir** + ım | gel**mem** / gel**mez** | gelir misin? |
| Geçmiş (-dı) | o'zak + **dı/tı** + m | gel**medi**m | geldin mi? |
| Geçmiş (-mış) | o'zak + **mış** + ım | gel**memiş**im | gelmiş misin? |
| Gelecek | o'zak + **acak/ecek** + ım | gel**meyeceğ**im | gelecek misin? |

**Shaxs qo'shimchalarining 2 turi:**

| Shaxs | 1-tur (-iyor, -r, -mış, -acak) | 2-tur (faqat -dı) |
|---|---|---|
| Ben | -(y)ım | -m |
| Sen | -sın | -n |
| O | — | — |
| Biz | -(y)ız | -k |
| Siz | -sınız | -nız |
| Onlar | -lar | -lar |

## 8. Mashqlar

Qavs ichidagi fe'lni kerakli zamonga qo'ying:

1. Şu an müzik ______ (dinlemek, ben, şimdiki).
2. Her gün spor ______ (yapmak, o, geniş).
3. Dün akşam ne ______? (yemek, sen, -dı)
4. Haftaya Ankara'ya ______ (gitmek, biz, gelecek).
5. Ahmet ______ (evlenmek, o, -mış) — eshitdim.
6. Ben kahve ______ (içmek, ben, geniş, inkor).
7. Kitabı ______ mı? (okumak, siz, -dı)
8. Yarın ______ (gelmek, onlar, gelecek, inkor).
9. Ne ______ ? (demek, sen, şimdiki)
10. Kapıyı ______ ? (açmak, sen, geniş, so'roq — iltimos)
