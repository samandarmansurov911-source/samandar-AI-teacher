Unli uyg'unligi (ünlü uyumu)

Turk tilida qo'shimchalar so'zning oxirgi unlisiga qarab o'zgaradi. Ikki xil uyg'unlik bor:

Oxirgi unli2 xilli (a / e)
a, ı, o, ua  (yazacak)
e, i, ö, üe  (gelecek)
Oxirgi unli4 xilli (ı / i / u / ü)
a, ıı  (alıyor)
e, ii  (geliyor)
o, uu  (oturuyor)
ö, üü  (görüyor)
Jarangsiz undoshlar: f, s, t, k, ç, ş, h, p. Eslab qolish uchun: "FıSTıKÇı ŞaHaP". Shu harflardan keyin d o'rniga t keladi: yap + dı → yaptı, iç + dı → içti, lekin gel + dı → geldi.
Fe'l o'zagi = infinitivdan -mak / -mek olib tashlanadi: gelmek → gel, yapmak → yap, okumak → oku.
1-zamon

Şimdiki zaman

-iyor · hozirgi davomli zamon

Qachon: hozir, shu daqiqada bo'layotgan ish; yaqin kelajakdagi reja; hozirgi davrdagi holat. O'zbekchada -yapman, -moqdaman.

o'zak + ı/i/u/ü + yor + shaxs qo'shimchasi
  • Undosh bilan tugasa: gel → geliyor, yaz → yazıyor, otur → oturuyor, gör → görüyor
  • Unli bilan tugasa, unli qo'shilmaydi: oku → okuyor, yürü → yürüyor
  • a / e bilan tugasa, u ı/i/u/ü ga aylanadi: bekle → bekliyor, anla → anlıyor, söyle → söylüyor

2-zamon

Geniş zaman

-r / -ar / -ir · umumiy (doimiy) zamon

Qachon: odatlar, umumiy haqiqatlar, iltimos va taklif, va'da, maqollar. O'zbekchada -aman, -asan, -adi (odatiy ma'noda).

  • Odat: Her sabah kahve içerim. Har tong qahva ichaman.
  • Haqiqat: Su 100 derecede kaynar. Suv 100 darajada qaynaydi.
  • Iltimos: Kapıyı açar mısın? Eshikni ochib yuborasanmi?
  • Va'da: Yarın ararım. Ertaga qo'ng'iroq qilaman.

3-zamon

Geçmiş zaman

-dı / -mış · o'tgan zamon

Turk tilida o'tgan zamonning ikki asosiy turi bor: o'zi ko'rgan ish uchun -dı, eshitgan ish uchun -mış.

3A. Görülen geçmiş zaman (-dı): aniq o'tgan zamon

Gapiruvchi ishni o'zi ko'rgan yoki aniq biladi. O'zbekchada -dim, -ding, -di.

o'zak + dı/di/du/dü (jarangsizdan keyin tı/ti/tu/tü) + m/n/k/nız/lar
  • geldi, okudu, gördü, aldı
  • yaptı, gitti, içti, konuştu
ShaxsBo'lishli (+)Bo'lishsiz (–)So'roq (?)
Bengeldimgelmedimgeldim mi?
Sengeldingelmedingeldin mi?
Ogeldigelmedigeldi mi?
Bizgeldikgelmedikgeldik mi?
Sizgeldinizgelmedinizgeldiniz mi?
Onlargeldilergelmedilergeldiler mi?
Eslatma: bu zamonda so'roq yuklamasi mi eng oxirida, shaxs qo'shimchasidan keyin keladi: geldin mi?
  • Dün sinemaya gittim. Kecha kinoga bordim.
  • Kahvaltı yaptın mı? Nonushta qildingmi?
  • Onlar ödevi yapmadılar. Ular uy vazifasini qilmadilar.

3B. Duyulan geçmiş zaman (-mış): eshitilgan o'tgan zamon

Ishni o'zi ko'rmagan, boshqadan eshitgan yoki keyin bilib qolgan; ajablanish. O'zbekchada -ibdi, -gan ekan, -ibman.

o'zak + mış/miş/muş/müş + ım/sın/–/ız/sınız/lar

4-zamon

Gelecek zaman

-acak / -ecek · kelasi zamon

Qachon: kelajakdagi ish, reja, qaror, bashorat. O'zbekchada -aman, -moqchiman.

o'zak + (y) + acak/ecek + shaxs qo'shimchasi
  • Undosh bilan tugasa: gelecek, yapacak
  • Unli bilan tugasa, y qo'shiladi: okuyacak, bekleyecek
Diqqat: unli bilan boshlanadigan shaxs qo'shimchasidan oldin k → ğ bo'ladi: gelecek → geleceğim, geleceğiz.
ShaxsBo'lishli (+)Bo'lishsiz (–)So'roq (?)
Bengeleceğimgelmeyeceğimgelecek miyim?
Sengeleceksingelmeyeceksingelecek misin?
Ogelecekgelmeyecekgelecek mi?
Bizgeleceğizgelmeyeceğizgelecek miyiz?
Sizgeleceksinizgelmeyeceksinizgelecek misiniz?
Onlargeleceklergelmeyeceklergelecekler mi?

Istisnolar

git → gideceğimboraman
et → edeceğimqilaman
de → diyeceğimdeyman
ye → yiyeceğimyeyman
  • Yarın sana yazacağım. Ertaga senga yozaman.
  • Gelecek yıl Türkiye'ye gideceğiz. Kelasi yil Turkiyaga boramiz.
  • Bu akşam ne yapacaksın? Bu kech nima qilmoqchisan?
  • O bu işi yapmayacak. U bu ishni qilmaydi.
So'zlashuvda: ko'pincha qisqa aytiladi: geleceğim → gelicem, yapacağım → yapıcam. Yozuvda esa to'liq shakl ishlatiladi.
